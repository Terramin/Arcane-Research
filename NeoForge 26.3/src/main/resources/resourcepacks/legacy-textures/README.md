# Thaumcraft Legacy Textures

Встроенный опциональный ресурс-пак со старыми (1.12) текстурами.
Поставляется внутри JAR мода, по умолчанию ВЫКЛЮЧЕН.

## Как включить

В игре: Настройки → Ресурспаки → «Thaumcraft Legacy Textures» → в правую
колонку → Готово.

## Что внутри

Только текстуры, отличающиеся от новых (`assets/thaumcraft/textures/**`).
Пути уже приведены к 1.20-раскладке (`blocks/` → `block/`,
`items/` → `item/`), так что пак переопределяет именно те текстуры,
которые грузит мод. Совпадающие файлы не включены — их подменяет сам мод.

## Отдельное использование

Папку можно вытащить из JAR как обычный пак: скопируй
`resourcepacks/legacy-textures/` из исходников или из собранного JAR
в `resourcepacks/` игры.

## Как пересобрать

Источником служат старые ассеты (`src/main/resources_old`, в гитигноре):

- старый файл `textures/blocks/<x>` → пак `textures/block/<x>`;
- старый файл `textures/items/<x>` → пак `textures/item/<x>`;
- остальные пути `textures/<...>` — без изменений;
- копируется файл, только если цель существует в `src/main/resources`
  и побайтово отличается (сверка MD5).

`pack_format: 15` = Minecraft 1.20.1.
